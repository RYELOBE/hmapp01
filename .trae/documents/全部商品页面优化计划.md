# 全部商品页面优化计划

## 📋 问题分析

### 当前问题

1. **数据未正确渲染**：API 返回 `{code: 200, data: {items: [...], totalCount: ...}}` 但前端解析逻辑不匹配
2. **布局过于简单**：缺少参考图中的层次感和专业感
3. **分页组件**：使用"加载更多"按钮，需改为标准分页器
4. **筛选功能弱化**：缺少多维度筛选选项

### 参考设计特点（第一张图片）

* 顶部 Hero 区域：渐变背景 + 标题/副标题 + 搜索框

* 左侧分类树 + 右侧多维度筛选标签

* 3列商品卡片网格

* 底部简洁分页器

***

## 🔧 实施步骤

### 步骤 1：修复数据渲染问题

**文件**: `packages/apps/campus-app/src/views/portal/buyer/Items.vue`

修改 `loadData()` 函数中的响应解析：

```javascript
// 修复前
const rows = res?.items || res?.rows || [];
total.value = res?.total || res?.totalCount || 0;

// 修复后
const data = res?.data || res;
const rows = data?.items || res?.items || res?.rows || [];
total.value = data?.totalCount || data?.total || res?.total || 0;
```

### 步骤 3：优化 Hero 区域样式

* 添加渐变背景（与首页风格统一）

* 居中布局：标题 + 副标题 + 搜索框

* 全宽显示，负 margin 技巧

### 步骤 4：添加左侧分类导航

* 固定宽度侧边栏（200px）

* 分类列表支持折叠

* 当前选中高亮显示

* 移动端自动隐藏或变为下拉菜单

### 步骤 5：优化筛选区域

* 多行筛选标签：

  * 第一行：商品类别（全部、电子产品、图书教材...）

  * 第二行：成色筛选（全新、99新、95新、9成新...）

  * 第三行：校区筛选（主校区、东校区、西校区...）

* 支持多选/单选切换

* "重置"按钮清除所有筛选

### 步骤 6：优化商品卡片展示

* 保持 3 列网格布局（桌面端）

* 卡片信息更丰富：

  * 图片（16:9）

  * 标题（2行截断）

  * 描述（1行截断）

  * 价格（醒目红色）

  * 成色标签

  * 校区 + 卖家名

  * 发布时间 + 浏览量

### 步骤 7：实现标准分页组件

替换"加载更多"为 Arco Design 的 `a-pagination` 组件：

```vue
<a-pagination
  :total="total"
  :current="currentPage"
  :page-size="pageSize"
  show-total
  show-jumper
  @change="handlePageChange"
/>
```

样式定制：

* 居中显示

* 圆角按钮

* 选中状态蓝色高亮

* 与整体风格统一

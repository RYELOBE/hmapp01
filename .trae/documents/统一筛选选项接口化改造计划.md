# 统一筛选选项接口化改造计划

## 📋 问题分析

### 当前问题
1. **成色筛选缺少"99新"**：前端 `conditions` 数组没有 `LIKE_NEW`（99新）选项
2. **校区硬编码**：`campuses` 写死为 `[全部校区, 主校区, 东校区, 西校区]`
3. **分类硬编码**：`categories` 和首页 `quickCategories` 都是写死的
4. **数据不一致**：首页有"其他物品"(OTHER)，全部商品页没有

### 根本原因
所有筛选项都是前端硬编码，与后端数据库实际值不同步，容易出错。

---

## 🔧 解决方案：新增统一字典接口

### 新增后端 API

```
GET /api/dict/options  → 返回所有筛选项配置
```

**响应格式**：

## 📝 实施步骤

### 步骤 1：创建后端字典 Controller + Service

**新建文件**: `backend/src/main/java/com/campus/marketplace/controller/DictController.java`

```java
@RestController
@RequestMapping("/dict")
public class DictController {

  @GetMapping("/options")
  public Map<String, Object> getOptions() {
    return buildSuccessResponse(Map.of(
      "categories", getCategories(),
      "conditions", getConditions(),
      "campuses", getCampuses()
    ));
  }
  
  // 返回分类列表（包含 OTHER）
  private List<Map<String, String>> getCategories() { ... }
  
  // 返回成色列表（包含 LIKE_NEW=99新）
  private List<Map<String, String>> getConditions() { ... }
  
  // 返回校区列表
  private List<Map<String, String>> getCampuses() { ... }
}
```

### 步骤 2：前端新增 API 调用

**修改文件**: `packages/apps/campus-app/src/services/api.js`

```javascript
export async function getDictOptions() {
  return await http.get('/dict/options');
}
```

### 步骤 3：重构 Items.vue 使用动态数据

**修改文件**: `packages/apps/campus-app/src/views/portal/buyer/Items.vue`

```javascript
// 之前：硬编码
const categories = [ { value: 'ELECTRONICS', label: '电子产品', ... }, ... ];
const conditions = [ { value: 'NEW', label: '全新' }, ... ];  // 缺少 LIKE_NEW!
const campuses = [ { value: '', label: '全部校区' }, ... ];

// 之后：从接口获取
const categories = ref([]);
const conditions = ref([]);
const campuses = ref([]);

onMounted(async () => {
  const dictData = await getDictOptions();
  categories.value = dictData.data.categories;
  conditions.value = dictData.data.conditions;   // 包含 99新
  campuses.value = dictData.data.campuses;
  loadData();
});
```

### 步骤 4：重构首页 Home.vue 使用动态分类

**修改文件**: `packages/apps/campus-app/src/views/portal/home/index.vue`

```javascript
// 之前：硬编码
const quickCategories = [
  { value: 'ELECTRONICS', label: '电子产品', icon: '📱' },
  ...
  { value: 'OTHER', label: '其他物品', icon: '🎁' },
];

// 之后：从接口获取
const quickCategories = ref([]);

onMounted(async () => {
  const dictData = await getDictOptions();
  quickCategories.value = dictData.data.categories;  // 自动包含 OTHER
  loadHotItems();
});
```

### 步骤 5：Layout.vue 导航分类同步（可选）

如果顶部导航也需要动态分类，同样使用接口数据。

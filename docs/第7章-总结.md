# 7 总结

本作使用Spring Boot 3框架，结合Java 17、Spring Security安全框架、JJWT令牌库、MySQL数据库和Vue 3前端技术，打造了一款基于校园场景的二手交易平台。系统为买家、卖家和运营人员三类角色提供了完整的交易流程支持，包括商品发布与审核、订单创建与支付、购物车与收藏、评价提交与审核、校园圈子互动以及AI智能助手等核心功能模块。后端实现了RESTful API接口和JWT无状态认证机制，前端使用Arco Design组件库构建了响应式用户界面，运营后台提供了数据仪表盘、审批工作台和系统管理等运营工具。

尽管本作平台尚存一些不足，例如部分页面响应速度有待优化、移动端适配仍需完善，但最终成果仍与我个人预期相契合。在平台开发过程中，Spring Security结合JWT的认证授权机制给我带来了相当大的困扰。平台中所有需要登录的接口都依赖于JWT令牌验证，但由于项目初期对SecurityConfig配置不够深入，导致自定义的JWT认证过滤器与Spring Security默认表单登录产生冲突，部分接口出现了403权限拒绝或无限重定向的问题。经过不断的尝试和探索，我采取了一种折衷的解决方案：在SecurityConfig中配置了请求匹配器，将公开接口（登录、注册、商品列表、圈子列表、字典接口）排除在认证链之外，对其他接口统一应用JWT过滤器，同时关闭了CSRF防护（因为JWT是无状态的），并妥善处理了跨域请求。这一优化过程显著改善了认证系统的稳定性和安全性，使得用户登录和API调用的体验更为流畅。未来，随着技术的不断进步和经验的积累，我期待能够进一步完善平台，为校园用户提供更加出色的二手交易体验。

总而言之，这次开发过程对我来说是一次极为宝贵的经历。我不仅接触并深入了解了全栈开发这一令我热爱的领域，还掌握了诸多开发之外的重要技能，如系统架构设计、RESTful API设计、数据库表结构设计、前后端分离开发模式以及pnpm Monorepo项目管理。特别是在集成智谱AI GLM-4模型实现AI智能助手的过程中，我学习了如何通过RAG（检索增强生成）技术构建知识库，让AI能够基于平台规则和业务知识为用户提供精准的问答服务。这些经历不仅锻炼了我的技术实力，更提升了我的学习能力与问题解决能力，为我未来在软件开发行业中的发展奠定了坚实的基础。展望未来，我将带着这次开发的经验与教训，持续进步，不断挑战自我，力求创作出更多优质、实用的软件作品。

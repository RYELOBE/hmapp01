# 5 系统核心模块设计与实现

## 5.1 核心模块设计概述

根据需求分析和系统架构设计，校园二手交易平台包含以下九个核心功能模块：

**（1）商品管理模块**

商品管理模块是平台的核心基础模块，承担商品的全生命周期管理。卖家发布商品后进入 PENDING_REVIEW 状态，运营审核通过后变为 APPROVED 状态方可上架展示。模块支持商品创建、分页查询、详情查看、编辑更新、下架删除、热度统计等功能，采用状态机控制商品流转，结合 item_stats 表实现浏览量、点击量、收藏量的热度评分算法。

**（2）订单交易模块**

订单交易模块实现从下单到交易完成的完整交易闭环。定义七种订单状态（PENDING_PAYMENT/PAID/SHIPPED/COMPLETED/CANCELLED/REFUNDING/REFUNDED），使用静态 Map 定义合法的状态转换关系，所有状态变更操作前必须通过 canTransition 方法校验。支持订单创建、模拟支付、发货、确认收货、取消、退款申请、同意/拒绝退款等全流程操作，并提供角色感知的订单列表查询。

**（3）购物车模块**

购物车模块为买家提供商品暂存和批量管理功能。支持添加商品、修改数量、选中/取消选中、批量操作和清空购物车。同一用户对同一商品只能有一条购物车记录，重复添加时自动合并数量（上限99）。购物车列表自动关联商品信息并计算已选商品总金额，支持按商品ID快速删除和检查商品是否在购物车中。

**（4）收藏模块**

收藏模块为买家提供商品收藏功能，支持一键收藏/取消收藏。同一用户对同一商品只能收藏一次，收藏/取消收藏时同步更新 item_stats 表的 favorite_count 和 hot_score。提供收藏列表查询、收藏状态检查、收藏数量统计等功能，收藏列表自动关联商品详情展示完整商品信息。

**（5）评价模块**

评价模块实现交易完成后的评价功能，包括买家评价、卖家回复、评价审核等环节。评价与订单和商品关联，每个已完成订单只能评价一次。支持1-5星评分、文字内容、图片等评价方式，评价提交后进入 PENDING 状态需运营审核通过后才公开展示。自动计算商品平均评分和评分分布，卖家或运营人员可对评价进行回复。

**（6）校园圈子模块**

校园圈子模块是平台的社交功能模块，提供类似校园论坛的帖子发布、评论、点赞等功能。帖子和评论均采用审核机制，创建后进入 PENDING 状态，运营审核通过后公开展示。采用 toggle 式点赞机制，同一用户对同一帖子只能点赞一次，再次点击取消点赞。支持按标签筛选帖子、查看我的帖子、浏览量自动递增等功能。

**（7）AI助手模块**

AI助手模块集成智谱AI GLM大语言模型，为用户提供智能问答服务。采用知识库检索增强生成（RAG）模式，用户提问时先从知识库检索相关内容作为AI回答的上下文。根据用户角色（BUYER/SELLER/OPS）调整AI回答策略，提供不同角色的预设问题列表。支持多会话管理、历史对话记录查看、会话标题自动生成等功能。

**（8）运营后台模块**

运营后台模块是平台的管理中枢，提供数据统计、用户管理、商品审核、订单管理、圈子审核、评价审核等全方位运营管理功能。采用独立的OPS角色认证体系，运营账号存储在ops_account表，独立于普通用户体系。提供多维度统计数据聚合（用户/商品/订单/评价/圈子），支持订单趋势、分类统计、状态分布等图表展示，统一的审批工作台处理各类审核任务。

**（9）用户管理模块**

用户管理模块负责用户认证授权和账户管理。采用Spring Security安全框架结合JWT令牌库实现无状态认证，用户注册时密码经BCrypt加密后存储。登录时验证账号密码，生成包含用户ID、用户名和角色信息的JWT令牌，有效期24小时。支持用户登录、注册、个人资料更新、头像修改、密码修改等功能，运营人员使用独立的登录接口和认证通道。前端通过路由守卫校验用户角色权限，Axios请求拦截器为每个请求注入认证头。

## 5.2 核心功能模块具体实现

### 5.2.1 商品管理模块

商品管理模块的后端采用 Controller-Service-Repository 三层架构。ItemController 定义 RESTful API 接口，使用 `@PreAuthorize` 注解实现方法级权限控制，仅 SELLER 角色可创建、更新、删除和下架商品。使用 Java 17 Record 类定义请求参数，结合 `@Validated` 注解实现参数校验。

ItemController 核心接口实现：

```java
@RestController
@RequestMapping("/api/items")
@Validated
public class ItemController {
  private final ItemService itemService;
  private final CurrentUserService currentUserService;
  private final ItemStatsService itemStatsService;

  @PostMapping
  @PreAuthorize("hasRole('SELLER')")
  public Map<String, Object> createItem(@RequestBody @Validated CreateItemRequest request) {
    return itemService.createItem(
        currentUserService.userId(),
        request.title(), request.price(), request.description(),
        request.imageUrls(), request.category(),
        request.conditionLevel(), null);
  }

  @GetMapping("/{id}")
  public Map<String, Object> detail(@PathVariable("id") Long id) {
    Map<String, Object> item = itemService.getItemDetail(id);
    itemStatsService.trackView(id);
    Object viewCount = item.get("viewCount");
    if (viewCount instanceof Number count) {
      item.put("viewCount", count.intValue() + 1);
    }
    return item;
  }

  @PostMapping("/{id}/off-shelf")
  @PreAuthorize("hasRole('SELLER')")
  public Map<String, Object> offShelf(@PathVariable("id") Long id) {
    itemService.offShelfItem(id, currentUserService.userId());
    // 发送商品下架通知给运营人员
    try {
      notificationService.createBusinessNotification(
        "ITEM", id.toString(), "商品已下架", "卖家已下架商品，ID: " + id, null);
    } catch (Exception e) {
      System.err.println("Failed to send off-shelf notification: " + e.getMessage());
    }
    return Map.of("code", 200, "message", "已下架");
  }

  public record CreateItemRequest(
      @NotBlank String title,
      @NotNull @Min(1) Integer price,
      @NotBlank String description,
      Object imageUrls,
      String category,
      String conditionLevel) {}
}
```

ItemService 实现商品核心业务逻辑，包括卖家验证、分页参数校验、图片URL解析等。createItem 方法验证卖家存在性后获取卖家昵称，解析图片URL列表，调用 Repository 保存并自动初始化统计数据。

```java
@Service
public class ItemService {
  private final ItemRepository itemRepository;
  private final UserRepository userRepository;

  public Map<String, Object> createItem(Long sellerId, String title, Integer price,
      String description, Object imageUrls, String category,
      String conditionLevel, String campus) {
    validateSeller(sellerId);
    String imageUrlsStr = parseImageUrls(imageUrls);
    return itemRepository.save(title, price, description, sellerId,
        getSellerNickname(sellerId), imageUrlsStr, category, conditionLevel, campus);
  }

  public Map<String, Object> listItemsPaged(Boolean approvedOnly, Boolean mine,
      String keyword, String category, String sort,
      String conditionLevel, String campus,
      int pageNo, int pageSize, Long userId) {
    validatePageParams(pageNo, pageSize);
    boolean showMine = Boolean.TRUE.equals(mine);
    boolean showApprovedOnly = Boolean.TRUE.equals(approvedOnly);

    String status = showApprovedOnly ? "APPROVED" : null;
    List<Map<String, Object>> rows;
    int total;

    if (showMine) {
      rows = itemRepository.findBySellerIdPaged(userId, null, pageNo, pageSize);
      total = itemRepository.countBySellerIdWithFilter(userId, null);
    } else {
      rows = itemRepository.findByPage(status, keyword, category, conditionLevel, campus, sort, pageNo, pageSize);
      total = itemRepository.countByFilter(status, keyword, category, conditionLevel, campus);
    }
    return buildSuccessResponse(Map.of(
      "items", rows, "totalCount", total,
      "pageNo", pageNo, "pageSize", pageSize));
  }
}
```

ItemRepository 基于 JdbcTemplate 实现数据访问，定义三种 RowMapper 分别映射基础商品数据、含统计数据的商品数据和含卖家详情的完整商品数据。分页查询采用动态 SQL 拼接，根据筛选条件动态添加 WHERE 子句。

商品详情查询使用多表 LEFT JOIN 关联 item、item_stats 和 user_account 表，并通过子查询获取卖家已售数量、平均评分和评价数量：

```java
@Repository
public class ItemRepository {
  private final JdbcTemplate jdbc;

  public Map<String, Object> findDetailById(Long id) {
    String sql = """
        SELECT i.*, COALESCE(s.view_count, 0) AS view_count,
               COALESCE(s.click_count, 0) AS click_count,
               COALESCE(s.favorite_count, 0) AS favorite_count,
               u.phone AS seller_phone,
               u.campus AS seller_campus,
               (SELECT COUNT(*) FROM orders o WHERE o.seller_id = i.seller_id AND o.status = 'COMPLETED') AS seller_sold_count,
               (SELECT COALESCE(ROUND(AVG(r.rating), 1), 5.0) FROM review r WHERE r.seller_id = i.seller_id AND r.status = 'APPROVED') AS seller_rating,
               (SELECT COUNT(*) FROM review r WHERE r.item_id = i.id AND r.status = 'APPROVED') AS review_count
        FROM item i
        LEFT JOIN item_stats s ON i.id = s.item_id
        LEFT JOIN user_account u ON i.seller_id = u.id
        WHERE i.id = ?
        """;
    List<Map<String, Object>> results = jdbc.query(sql, DETAIL_ROW_MAPPER, id);
    return results.isEmpty() ? null : results.get(0);
  }

  public Map<String, Object> save(String title, Integer price, String description,
      Long sellerId, String sellerName, String imageUrls, String category,
      String conditionLevel, String campus) {
    KeyHolder kh = new GeneratedKeyHolder();
    jdbc.update(con -> {
      var ps = con.prepareStatement(
          "INSERT INTO item (title, price, description, seller_id, seller_name, review_status, image_urls, category, condition_level, campus) VALUES (?, ?, ?, ?, ?, 'PENDING_REVIEW', ?, ?, ?, ?)",
          Statement.RETURN_GENERATED_KEYS);
      ps.setString(1, title);
      ps.setInt(2, price);
      ps.setString(3, description);
      ps.setLong(4, sellerId);
      ps.setString(5, sellerName);
      ps.setString(6, imageUrls);
      ps.setString(7, category);
      ps.setString(8, conditionLevel);
      ps.setString(9, campus);
      return ps;
    }, kh);
    Long id = kh.getKey().longValue();
    jdbc.update("INSERT IGNORE INTO item_stats (item_id, view_count, click_count, favorite_count, hot_score) VALUES (?, 0, 0, 0, 0.00)", id);
    return findById(id);
  }
}
```

### 5.2.2 订单交易模块

订单交易模块的核心是状态机控制。OrderService 使用静态 Map 定义合法的状态转换关系，所有状态变更操作前通过 canTransition 方法校验。OrderController 类级别使用 `@PreAuthorize("isAuthenticated()")` 确保所有订单操作需登录，退款审批额外要求 OPS 或 SELLER 角色。

```java
@RestController
@RequestMapping("/api/orders")
@PreAuthorize("isAuthenticated()")
public class OrderController {
  private final OrderService orderService;
  private final CurrentUserService currentUserService;

  @PostMapping
  @PreAuthorize("hasAnyRole('BUYER', 'SELLER', 'OPS')")
  public Map<String, Object> createOrder(@RequestBody CreateOrderRequest request) {
    Map<String, Object> order = orderService.createOrder(
        currentUserService.userId(),
        request.itemId(),
        request.quantity() != null ? request.quantity() : 1,
        request.receiverName(), request.receiverPhone(), request.receiverAddress());
    return Map.of("code", 200, "data", order);
  }

  @PostMapping("/{id}/ship")
  public Map<String, Object> ship(@PathVariable Long id, @RequestBody ShipRequest request) {
    orderService.ship(id, currentUserService.userId(), request.expressCompany(), request.expressNo());
    return Map.of("code", 200, "message", "发货成功");
  }

  @PostMapping("/{id}/refund/approve")
  @PreAuthorize("hasRole('OPS') or hasRole('SELLER')")
  public Map<String, Object> approveRefund(@PathVariable Long id) {
    orderService.approveRefund(id, currentUserService.userId());
    return Map.of("code", 200, "message", "退款成功");
  }

  public record CreateOrderRequest(
      Long itemId, Integer quantity,
      String receiverName, String receiverPhone, String receiverAddress) {}

  public record ShipRequest(String expressCompany, String expressNo) {}
}
```

OrderService 实现订单核心业务逻辑，状态机转换映射如下：

```java
@Service
public class OrderService {
  private final OrderRepository orderRepository;
  private final ItemRepository itemRepository;

  private static final Map<String, List<String>> STATUS_TRANSITIONS = Map.of(
      "PENDING_PAYMENT", List.of("PAID", "CANCELLED"),
      "PAID", List.of("SHIPPED", "CANCELLED", "REFUNDING"),
      "SHIPPED", List.of("COMPLETED", "REFUNDING"),
      "REFUNDING", List.of("REFUNDED", "PAID"),
      "COMPLETED", List.of(),
      "CANCELLED", List.of(),
      "REFUNDED", List.of()
  );

  private boolean canTransition(String currentStatus, String nextStatus) {
    List<String> allowed = STATUS_TRANSITIONS.get(currentStatus);
    return allowed != null && allowed.contains(nextStatus);
  }

  public Map<String, Object> createOrder(Long buyerId, Long itemId, Integer quantity,
      String receiverName, String receiverPhone, String receiverAddress) {
    validateBuyer(buyerId);
    validateOrderParams(itemId, quantity, receiverName, receiverPhone);

    Map<String, Object> item = itemRepository.findById(itemId);
    if (item == null) throw new IllegalArgumentException("商品不存在");
    if (!"APPROVED".equals(item.get("reviewStatus"))) throw new IllegalArgumentException("商品未上架");
    if (orderRepository.hasActiveOrder(buyerId, itemId)) throw new IllegalArgumentException("您已有该商品的进行中订单");

    Long sellerId = ((Number) item.get("sellerId")).longValue();
    if (buyerId.equals(sellerId)) throw new IllegalArgumentException("不能购买自己的商品");

    return orderRepository.save(buyerId, sellerId, itemId,
        (String) item.get("title"), (String) item.get("imageUrls"),
        ((Number) item.get("price")).intValue(), quantity,
        receiverName, receiverPhone, receiverAddress,
        getBuyerName(buyerId), (String) item.get("sellerName"));
  }

  public Map<String, Object> getMinePaged(Long userId, List<String> roles, String status, int pageNo, int pageSize) {
    validatePageParams(pageNo, pageSize);
    boolean isSeller = roles.contains("SELLER");
    boolean isBuyer = roles.contains("BUYER");

    if (isSeller && isBuyer) {
      List<Map<String, Object>> buyerRows = orderRepository.findByBuyerIdPaged(userId, status, pageNo, pageSize);
      List<Map<String, Object>> sellerRows = orderRepository.findBySellerIdPaged(userId, status, pageNo, pageSize);
      rows = new ArrayList<>(buyerRows);
      rows.addAll(sellerRows);
      rows.sort((a, b) -> String.valueOf(b.getOrDefault("createdAt", "")).compareTo(String.valueOf(a.getOrDefault("createdAt", ""))));
      rows = rows.stream().limit(pageSize).toList();
      total = orderRepository.countByBuyerIdWithFilter(userId, status) + orderRepository.countBySellerIdWithFilter(userId, status);
    } else if (isSeller) {
      rows = orderRepository.findBySellerIdPaged(userId, status, pageNo, pageSize);
      total = orderRepository.countBySellerIdWithFilter(userId, status);
    } else {
      rows = orderRepository.findByBuyerIdPaged(userId, status, pageNo, pageSize);
      total = orderRepository.countByBuyerIdWithFilter(userId, status);
    }
    return Map.of("code", 200, "data", Map.of(
        "orders", rows, "totalCount", total,
        "pageNo", pageNo, "pageSize", pageSize));
  }
}
```

OrderRepository 支持多维度分页查询和统计。订单号生成采用 "ORD + 时间戳 + 随机数" 格式，运营端查询支持多字段模糊搜索（order_no/item_title/buyer_name/seller_name）。

### 5.2.3 购物车模块

购物车模块提供商品暂存和批量管理功能。CartController 定义完整的购物车操作接口，包括添加、更新数量、选中/取消选中、批量操作、删除和清空。使用 Record 类定义请求参数，结合 `@Validated` 注解实现数量范围校验（1-99）。

CartService 实现购物车核心业务逻辑。添加商品时，若购物车中已存在该商品则自动合并数量（上限99）。购物车列表查询关联商品信息，自动计算已选商品总金额：

```java
@Service
public class CartService {
  private final CartRepository cartRepository;
  private final ItemRepository itemRepository;

  public Map<String, Object> addToCart(Long userId, Long itemId, int quantity) {
    if (quantity < 1 || quantity > 99) throw new IllegalArgumentException("数量必须在1-99之间");

    var item = itemRepository.findById(itemId);
    if (item == null) throw new IllegalArgumentException("商品不存在");
    if (!"APPROVED".equals(item.get("reviewStatus"))) throw new IllegalArgumentException("商品未上架");

    var existingOpt = cartRepository.findByUserIdAndItemId(userId, itemId);
    if (existingOpt.isPresent()) {
      Map<String, Object> existing = existingOpt.get();
      int newQuantity = (int) existing.get("quantity") + quantity;
      if (newQuantity > 99) newQuantity = 99;
      cartRepository.updateQuantity((Long) existing.get("id"), newQuantity);
      return Map.of("code", 200, "message", "已更新购物车数量",
          "data", cartRepository.findById((Long) existing.get("id")).orElseThrow());
    }
    Map<String, Object> cartItem = cartRepository.create(userId, itemId, quantity, true);
    return Map.of("code", 200, "message", "已加入购物车", "data", cartItem);
  }

  public Map<String, Object> getCartList(Long userId) {
    List<Map<String, Object>> cartItems = cartRepository.findByUserId(userId);
    List<Map<String, Object>> result = new ArrayList<>();
    int totalAmount = 0;

    for (Map<String, Object> cart : cartItems) {
      Long itemId = (Long) cart.get("itemId");
      var item = itemRepository.findById(itemId);
      if (item != null) {
        Map<String, Object> enrichedItem = new HashMap<>(cart);
        enrichedItem.put("item", item);
        if ((Boolean) cart.get("selected")) {
          totalAmount += (int) item.get("price") * (int) cart.get("quantity");
        }
        result.add(enrichedItem);
      }
    }
    return Map.of("code", 200, "data", result, "totalAmount", totalAmount);
  }
}
```

CartRepository 基于 JdbcTemplate 实现，利用 uk_user_item 联合唯一索引防止重复添加。批量更新选中状态使用动态 SQL 拼接 IN 子句。

```java
@Service
public class FavoriteService {
  private final FavoriteRepository favoriteRepository;
  private final ItemRepository itemRepository;

  public Map<String, Object> addFavorite(Long userId, Long itemId) {
    var item = itemRepository.findById(itemId);
    if (item == null) throw new IllegalArgumentException("商品不存在");
    if (favoriteRepository.existsByUserIdAndItemId(userId, itemId)) return Map.of("code", 200, "message", "已收藏");
    favoriteRepository.create(userId, itemId);
    return Map.of("code", 200, "message", "收藏成功");
  }

  public Map<String, Object> getFavoriteList(Long userId) {
    List<Map<String, Object>> favorites = favoriteRepository.findByUserId(userId);
    List<Map<String, Object>> result = new ArrayList<>();

    for (Map<String, Object> fav : favorites) {
      Long itemId = (Long) fav.get("itemId");
      var item = itemRepository.findById(itemId);
      if (item != null) {
        Map<String, Object> enriched = new java.util.HashMap<>(fav);
        enriched.put("item", item);
        enriched.put("isFavorited", true);

      }
    }

public class AIService {

    String currentSessionId = sessionRepository.createOrReuseSession(sessionId, userId);
    sessionRepository.updateSessionTime(currentSessionId);

    var knowledgeChunks = knowledgeRepository.search(message);
    List<String> references = knowledgeChunks.stream()

    messageRepository.save(currentSessionId, "user", message, referencesJson);
    sessionRepository.updateSessionTitle(currentSessionId, message);

    String answer = callRealAI(message, role, references);
    messageRepository.save(currentSessionId, "assistant", answer, null);

    return Map.of("code", 200, "sessionId", currentSessionId, "reply", answer, "references", references);

  private String callRealAI(String message, String role, List<String> references) {
    StringBuilder systemPrompt = new StringBuilder("你是一个校园二手交易平台的智能助手。");

    }
    systemPrompt.append("\n如果问题不在知识范围内，请礼貌地告诉用户。");

@Service
public class AuthService {
  private final UserRepository userRepository;
  private final JwtUtil jwtUtil;
  private final PasswordEncoder passwordEncoder;

  public Map<String, Object> login(String username, String password) {
    var userOpt = userRepository.findByUsername(username);
    if (userOpt.isEmpty()) throw new IllegalArgumentException("用户名或密码错误");
    var user = userOpt.get();
    if (!passwordEncoder.matches(password, (String) user.get("password")))
      throw new IllegalArgumentException("用户名或密码错误");

    Long userId = (Long) user.get("id");
    List<String> roles = parseRoles((String) user.get("roles"));
    String token = jwtUtil.generateToken(username, roles, userId);

    Map<String, Object> response = new HashMap<>();
    response.put("token", token);
    response.put("tokenType", "Bearer");
    response.put("user", sanitizeUser(user));
    return response;
  }

  public Map<String, Object> register(String username, String password, String nickname, List<String> roles) {
    if (userRepository.findByUsername(username).isPresent())
      throw new IllegalArgumentException("用户名已存在");

    String encodedPassword = passwordEncoder.encode(password);
    Map<String, Object> user = userRepository.save(username, encodedPassword,
        nickname, roles != null ? String.join(",", roles) : "BUYER");

    Long userId = (Long) user.get("id");
    List<String> userRoles = parseRoles((String) user.get("roles"));
    String token = jwtUtil.generateToken(username, userRoles, userId);

    Map<String, Object> response = new HashMap<>();
    response.put("token", token);
    response.put("tokenType", "Bearer");
    response.put("user", sanitizeUser(user));

}
```

UserRepository 基于 JdbcTemplate 实现用户数据访问。JWT 认证过滤器继承 OncePerRequestFilter，从 Authorization 请求头提取 Bearer 令牌，使用 JwtUtil 解析验证，提取用户名、用户ID、角色信息，构建 UsernamePasswordAuthenticationToken 设置到 SecurityContext。安全配置类定义 HTTP 请求权限规则，公开登录、注册、商品列表、圈子列表、字典接口，其他接口需认证访问，采用 SessionCreationPolicy.STATELESS 无状态会话策略。

## 5.3 模块间协作关系

### 5.3.1 商品→订单→评价完整业务流程

平台最核心的业务闭环是商品发布到交易完成评价的完整流程：

1. **商品发布与审核**：卖家发布商品 → 商品进入 PENDING_REVIEW 状态 → 运营审核 → 通过则 APPROVED（上架），拒绝则 REJECTED
2. **商品浏览与互动**：买家浏览已上架商品 → 可收藏、加入购物车、查看详情 → 浏览/点击/收藏行为自动记录到 item_stats
3. **订单创建与支付**：买家下单 → 订单进入 PENDING_PAYMENT 状态 → 买家支付 → 订单进入 PAID 状态
4. **发货与收货**：卖家发货（填写快递信息）→ 订单进入 SHIPPED 状态 → 买家确认收货 → 订单进入 COMPLETED 状态
5. **评价与审核**：买家对已完成订单评价 → 评价进入 PENDING 状态 → 运营审核 → 通过则 APPROVED（公开展示），拒绝则 REJECTED → 卖家可回复评价

### 5.3.2 运营后台与各模块的监管关系

运营后台作为平台管理中枢，与各业务模块存在监管关系：

1. **商品监管**：运营可审核商品（通过/驳回）、查看待审核数量、查看分类统计
2. **订单监管**：运营可查看所有订单、审批退款申请、查看订单趋势和状态分布
3. **圈子监管**：运营可审核帖子和评论、查看待审核数量
4. **评价监管**：运营可审核评价（通过/驳回/删除）、回复评价、查看待审核数量
5. **用户监管**：运营可修改用户角色、禁用/启用用户、查看供方（卖家）和需方（买家）统计

### 5.3.3 安全架构与认证体系

系统采用双轨认证体系，普通用户和运营人员使用独立的认证通道：

1. **无状态会话**：SessionCreationPolicy.STATELESS，基于 JWT Token 认证
2. **CSRF 禁用**：前后端分离架构，使用 Token 认证而非 Cookie
3. **方法级权限**：使用 `@PreAuthorize` 注解实现细粒度权限控制
4. **密码加密**：BCrypt 算法加密存储密码
5. **双表隔离**：user_account 和 ops_account 物理隔离，防止权限越权

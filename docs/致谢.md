# 致  谢

蓦然回首，时光如梭。转眼就到了该分别的时候了，回想我刚踏入怀化学院的时候，那是在2022年的一个盛夏，当时的我刚到学校还很迷茫，是在志愿者的帮助下才办好了各种的手续，也是从那天起开始了我的本科生活。回首大学时光，百感交集，在这四年的时光里我得到了众多的帮助和支持，我衷心地向他们表达感谢。

首先，我要向刘毅文老师致以最深的谢意。在整个论文撰写过程中，刘老师始终给予我悉心的指导和宝贵的建议。从开题之处的迷茫，到平台的功能设计上，再到毕设论文上的缺项，是刘老师始终耐心指出我的不足，为我一次次纠正论文中出现的错误。记得在做Spring Boot后端和Vue 3前端联调的时候，我遇到了接口跨域和JWT认证的问题，困扰了我很长一段时间，是刘老师帮我一步步分析原因，指出SecurityConfig配置和JWT过滤器中的问题所在。还有数据库表结构设计的时候，我一开始的表关系设计不够合理，也是刘老师帮我梳理了买家、卖家、商品、订单之间的关联逻辑，让我重新调整了表结构。正是有了刘老师的帮助，我才能够不断完善平台，完成了最终作品。在此我衷心感谢刘老师对我的帮助和指导。

其次，我要感谢班上的同学们。他们在我大学生涯中一直给予我无私的关怀和鼓励。我们一同探讨问题，相互学习，携手前行。从他们身上，我学到了许多我从未拥有过的技能和知识。其中我要特别感谢曾涛同学，在我项目遇到技术文档瓶颈时，他主动帮我排查问题，陪我一起调试代码，最终解决了困扰我好几天的bug。特别是在做AI智能助手模块的时候，我在集成智谱AI接口和RAG知识库的过程中遇到了不少问题，是曾涛同学帮我一起查阅资料、分析日志，最终找到了问题的根源。还有在写论文的过程中，我们经常互相审阅对方的论文初稿，指出格式和表述上的问题，这种互相促进的学习氛围让我受益匪浅。在此我十分感谢他的帮助。

同时，我还要感谢我的母校——怀化学院。感谢母校为我们提供了优良的学习环境和资源，让我们能够专心致志地追求知识。学校的机房、图书馆和网络资源都给了我很大的帮助，让我能够安心地把时间和精力投入到学习和项目开发中。在这里，我不仅学到了专业知识，还收获了宝贵的人生经验和成长。

最后，我要感谢我的父母。正是因为有他们在背后支持我鼓励我，我才能够在学校里毫无顾虑地追求我所热爱的知识。每当我遇到困难时，我的父母总是第一时间给予我鼓励和力量，让我勇往直前。我的父母为我付出了太多，我将永远铭记在心，感激不尽。

在道德经中有句话，"人生如虚空大梦一场，韶华白首不过转瞬"。转眼人生已过20余载，我衷心感激所有在我成长道路上给予帮助和支持的人。在未来的岁月里，我将珍惜时光不断努力，为实现自己的价值和梦想而奋斗。希望我能以实际行动回报所有关心和支持我的人，不辜负这段宝贵的青春时光。
